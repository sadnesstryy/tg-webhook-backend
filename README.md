## Getting start
Необходимо создать .env файл с данными
# API_PORT=8888 (по умолчанию 8888)
# TELEGRAM_BOT_TOKEN= (берём с BotFather в телеграмме)
# TELEGRAM_WEBHOOK_URL= (берём с ngrok на порте, где запущен сервер)
# CLIENT_URL= (берём с клиента)

# Устанавливаем зависимости npm install
# Запускаем сервер npm run dev
